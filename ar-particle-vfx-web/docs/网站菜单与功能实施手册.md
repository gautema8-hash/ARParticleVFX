## 步骤 2：实现 hash 路由

**目标**：让菜单链接能切换页面视图。

**前置**：步骤 1。

**操作**：新建 `src/router.js`：

```js
// src/router.js
const routes = {
  '/': (p) => renderHome(p),
  '/effects': (p) => renderCatalog(p),
  '/ar': () => renderAR(),
  '/pricing': () => renderPricing(),
  '/enterprise': () => renderEnterprise(),
  '/tools': () => renderTools(),
  '/help': () => renderHelp(),
  '/effect/:id': (id) => renderDetail(id)
};

export function initRouter(app) {
  function parse() {
    const raw = location.hash.replace(/^#/, '') || '/';
    const [path, query] = raw.split('?');
    const params = new URLSearchParams(query || '');
    const seg = path.split('/').filter(Boolean);
    if (seg[0] === 'effect' && seg[1]) {
      return routes['/effect/:id'](seg[1]);
    }
    return (routes[path] || routes['/'])(params);
  }
  window.addEventListener('hashchange', parse);
  parse();
}
```

**验收点**：浏览器地址栏 `#/effects`、`#/pricing` 等能触发对应渲染函数。

**可行性**：✅ 高。原生 hash 路由，零依赖。

## 步骤 3：页面容器与视图框架

**目标**：建立「页面容器 + 视图渲染」框架，各视图独立文件。

**前置**：步骤 2。

**操作**：
1. `index.html` 增加 `<main id="app"></main>`（导航栏下方、粒子场景之上，或独立占位）。
2. 新建 `src/views/`，每页一个文件：`home.js / catalog.js / detail.js / ar.js / pricing.js / enterprise.js / tools.js / help.js`。
3. 每个视图导出 `render(container, params)`，负责把内容写入 `#app`。

```js
// src/views/catalog.js 骨架
export function renderCatalog(app, params) {
  const cat = params.get('category') || 'all';
  app.innerHTML = `<h2>特效中心</h2><p>当前分类：${cat}</p>`;
  // 后续：渲染特效卡片列表（见步骤 4）
}
```

**验收点**：切换 hash，`#app` 内容随视图变化。

**可行性**：✅ 高。（路由 + 视图框架打通，后续逐页实现）

## 步骤 4：特效中心列表页（筛选器 + 卡片）

**目标**：实现特效总库列表页，含多维筛选与特效卡片。

**验收点**：列表能按分类/模式/权益筛选；点击卡片进入详情页。

**可行性**：✅ 高。
