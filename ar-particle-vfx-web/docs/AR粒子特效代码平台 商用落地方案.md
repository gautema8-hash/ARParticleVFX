# AR粒子特效代码平台 商用落地方案（兼容 demo001 现有项目 · 可落地版）

## 〇、现状基线：与现有项目（demo001）的关系与兼容性

> 本方案不是从零规划，而是**基于现有 `demo001`（Vite + 原生 JS + Three.js + MediaPipe 的 WebAR 手势粒子 Demo）向上演进**。平台的核心差异化能力已在现有项目中验证，落地属于「从 1 到 N」。

### 0.1 现有项目已具备、可直接复用的能力

| 现有能力 | 所在文件 | 平台侧复用点 |
| --- | --- | --- |
| 摄像头采集（getUserMedia + 中文错误处理） | src/camera.js | WebAR 实景交互底座 ✅ |
| 手势识别（MediaPipe HandLandmarker，21 关键点 × 2 手） | src/handTracker.js | 「AR 专属特效」核心 ✅ |
| 手势状态机（OPEN/PINCH/GRAB/NONE + 手掌大小） | src/gestureRecognizer.js | AR 交互判定 ✅ |
| 粒子引擎（六层粒子 + ShaderMaterial + AdditiveBlending + Bloom） | src/particleScene.js | 「特效引擎」，可抽象为特效模板 ✅ |
| 人像分割 + 图片粒子重构（10 万粒子高保真） | src/segmenter.js + main.js | 「人像粒子」差异化特效 ✅ |
| 特效模式切换 + 参数面板（大小/速度/光晕） | index.html + main.js | 「参数调节面板」雏形 ✅ |
| 屏幕录制（60FPS WebM/MP4） | src/recorder.js | 增值功能 ✅ |
| 图片/音频上传叠加 | main.js | 特效素材能力 ✅ |
| 模型/wasm 静态资源本地化 | vite.config.js（publicDir: models） | 单文件导出的资源内联基础 ✅ |

### 0.2 兼容性结论（与原方案的 3 处关键修正）

1. **前端框架**：原方案写 Next.js + React；现有项目是 **Vite + 原生 JS**。→ MVP 阶段**保留 Vite + 原生 JS（零重写）**，Next.js 仅作为 SEO 优化阶段的可选演进，不做起点。
2. **WebAR 底座**：原方案写 AR.js + A-Frame；现有项目用 **MediaPipe（手势 + 人像分割）**。→ 以 **MediaPipe 为 AR 底座**（复用现有代码），AR.js 仅作「图像识别 AR」的可选补充。
3. **后端**：原方案写 Nest.js + MySQL + Redis；现有项目**零后端**。→ MVP 用**轻量 BaaS（Supabase/LeanCloud）+ 本地 localStorage** 替代自建后端，阶段二再按需上自建后端。

## 一、项目定位与商业价值

### 1. 项目定位

国内首个**Web端AR粒子特效素材与代码工具平台**，聚焦前端开发者、UI设计师、电商运营、H5制作从业者，提供开箱即用的Canvas/WebGL粒子特效，支持普通网页特效与WebAR实景特效双模式，核心能力为「一键复制代码、单文件HTML导出」，零门槛降低粒子特效开发成本。

### 2. 核心商业价值

- **供给侧**：将零散的粒子特效标准化、分类化，解决开发者从零写粒子代码效率低、AR特效开发门槛高的痛点
- **需求侧**：覆盖官网首页、活动落地页、H5邀请函、数字展厅、个人博客等多场景特效需求
- **差异化**：主打「WebAR粒子」赛道，无需下载APP，浏览器即可调用摄像头实现实景粒子叠加，区别于普通代码素材站

### 3. 目标用户

- 核心用户：前端开发工程师、前端外包从业者
- 次核心用户：UI/UX设计师、电商运营、新媒体H5制作者
- 长尾用户：个人站长、学生、数字艺术爱好者

### 1. 技术栈对比与适配结论

| 模块 | 原方案 | 现有项目（demo001） | 适配后结论 |

| 后端服务 | Node.js + Nest.js | 无（纯前端） | MVP 用 BaaS（Supabase/LeanCloud）；阶段二按需上 Nest+MySQL |
| 数据存储 | MySQL + Redis | 无 | MVP：BaaS 内置库 + localStorage；阶段二：MySQL+Redis |
| 静态资源 | OSS/七牛云 | 本地 models/ + dist/ | 保持本地化；上线迁 OSS |
| 支付体系 | 微信/支付宝 | 无 | 需企业主体 + ICP 备案 + 对接 |

### 2. 核心功能技术实现（复用现有代码）

#### （1）特效引擎抽象（复用 particleScene.js）
- 把现有 `makePoints` + `ShaderMaterial` + `AdditiveBlending` 六层粒子架构抽象为「特效模板」：每个特效 = 一份参数配置（粒子数/颜色/尺寸/速度/着色器）+ 一个更新函数。
- 现有 `galaxy / ocean / photoParticle` 三个模式即首批 3 个「AR 专属特效」模板，可直接入库。

#### （2）一键复制 / 单文件导出（复用 Vite 构建产物 + Blob）
- 每个特效编译为**独立单文件 HTML**：JS/CSS 内联，模型/wasm 用 **Base64 内联或 CDN 引用**两种模式。
- 复制/导出用 `Clipboard API`（降级 `execCommand`）/ `Blob + URL.createObjectURL`（与 recorder.js 导出 Blob 同思路）。
- 免费版代码注入版权注释，会员版去除（导出模板按会员态条件渲染）。

#### （3）参数调节面板（复用现有 panel）
- 现有 `sizeFactor / speedFactor / bloomStrength` 滑块即「参数调节面板」雏形；扩展为通用 schema（粒子数/颜色/大小/速度/发射角/透明度），调节后重新序列化特效配置并生成代码。

#### （4）WebAR 实景（复用 camera + handTracker + particleScene）
- 无标记 AR：复用现有「摄像头 → 手势 → 粒子」链路，粒子随手势/陀螺仪运动。
- 图像识别 AR：复用 ImageSegmenter（已有 selfie_segmenter）或新增 AR.js marker 识别作可选增强。

### 3. 性能与兼容性保障
- 特效预览懒加载（列表页只加载封面）。
- 复用现有性能优化：Float32Array 直写、AdditiveBlending、`Math.min(devicePixelRatio,2)`、检测按视频帧节流、复原静止态跳过重算。
- 每个特效标注性能分级与设备/浏览器支持范围。

### 4. 落地工程结构（商用标准：Monorepo）

> 从「单页 Demo」升级为「平台」，推荐采用 **pnpm/npm workspace Monorepo**，前后端、特效引擎、特效库、导出器**分包管理**，支持独立版本化、可发布、可复用、可测试。

```
arpfx-platform/                        # 平台 monorepo（pnpm workspace）
├── package.json                       # workspace 脚本
├── pnpm-workspace.yaml
├── tsconfig.base.json                 # 共享 TS 配置（新代码走 TS，引擎可渐进迁移）
├── .eslintrc.cjs / .prettierrc        # 统一代码规范
├── .gitignore                         # 忽略 node_modules/dist/.env
├── .env.example                       # 环境变量模板（不含密钥）
```

### 4.2 商用标准的 6 条目录实践

1. **特效引擎独立成包**：版本化发布，单文件导出时按需打包，后续对外 API 直接复用。
2. **特效模板数据驱动**：每个特效 = 独立目录（config + 更新函数 + 封面），注册表统一枚举，便于量产与审核。
3. **资产不入代码仓库**：大模型/预览图走 Git LFS 或 CDN/OSS；**版权音频禁止入仓**。
4. **配置与代码分离**：`.env.example` + 运行时注入，密钥绝不入库。
5. **CI/CD 自动化**：push 自动 lint/test/build，main 自动部署。
6. **工程化规范**：TypeScript + ESLint + Prettier + Conventional Commits + 语义化版本。

## 九、成本与风险预估

### 1. 初期投入（MVP 阶段）
- 开发成本：前端 1 人 + 后端 1 人（或 1 人全栈 + BaaS），自研约 2-3 个月；外包约 5-8 万元。
- 特效制作：30 款原创特效，单款 200-500 元，合计约 1-2 万元。
- 服务器与存储：初期云服务器 + OSS（或 Vercel/Netlify 免费档），月均 500-1000 元。
- 资质与支付：企业主体、ICP 备案、支付对接，约 5000 元。

### 2. 核心风险与应对
- **版权风险（最高优先级）**：替换内置周杰伦音频；所有特效原创或正规授权；上线侵权投诉通道。
- **侵权风险**：代码自查避免抄袭。
- **兼容性风险**：重点适配 Chrome/Safari/微信内置浏览器，AR 功能标注支持范围。
- **用户留存风险**：每周 2-3 款上新，工具箱功能提升留存。
- **流量获取风险**：SEO、技术社区、短视频教程多渠道引流，避免单一依赖。
